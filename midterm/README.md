# Online Banking System - Midterm Project

## Project Overview
This is a complete online banking system website created using HTML, CSS, Bootstrap, and JavaScript. The project demonstrates responsive web design principles and modern banking interface design.

## Features Implemented

### Pages
1. **Home** - Main landing page with hero section, features, and testimonials
2. **About** - Company information, mission, vision, and leadership team
3. **Services** - Banking services with pricing table and detailed offerings
4. **Gallery** - Image gallery with filtering and blog posts
5. **Contact** - Contact form, information, and FAQ section

### HTML Features
- Semantic HTML5 elements
- Navigation with Bootstrap navbar
- Contact form with validation
- Pricing table with comparison
- Responsive image galleries
- Testimonials section

### CSS Features
- Custom styling with Flexbox and Grid layouts
- Positioning techniques (relative/absolute/fixed)
- Responsive design with media queries
- Custom animations and transitions
- Mobile-first approach

### Bootstrap Features
- Grid system for responsive layout
- Utility classes for spacing and alignment
- Components (cards, navbars, accordions)
- Responsive breakpoints
- Mobile navigation

### Responsive Design
- Desktop, tablet, and mobile layouts
- Media queries for different screen sizes
- Touch-friendly navigation
- Responsive images and content

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- Font Awesome Icons
- JavaScript (for form validation)

## How to Run
1. Extract all files to a folder
2. Open `index.html` in a web browser
3. Navigate through the site using the navigation menu

## Design Philosophy
The design focuses on:
- Security and trust (blue color scheme)
- Modern and clean interface
- User-friendly navigation
- Mobile-first responsive design
- Professional banking aesthetic
